 Step 1- added theme context in context/themeContext.tsx file. We can use this themeContext anywhere in app -
 const { theme, toggleTheme } = useTheme();  //theme will give - light/dark. toggleTheme is func to switch theme.
 
 Inside themecontext provider,  we are passing material ui theme provider where we need to pass muiTheme. 
  <MuiThemeProvider theme={muiTheme}>
  
  Step 2- we are building this muiTheme in theme/muiTheme. we can add any colors here but colors are not static. we are reading
  colors here from styles/colors.scss file. where we are adding colors for light and dark theme and reading those colors here.

  we are defining colors in sepearte file so we can use them inside components like -

   <ListItemButton
                  selected={active}
                  onClick={() => navigate(item.path)}
                  sx={{
                    justifyContent: open ? "initial" : "center",
                    px: 2.5,
                    "&.Mui-selected": {
                      backgroundColor: "var(--primary-selected)",  //this will automatically work for light/dark theme.
                    },
                  }}

OPTION 2- 
    OR i have just created a utils function in utils/extractCssVars.ts. what it does, it reads colors.scss file and extarct colors
    in an array of object like [{name: colorVal}]. 
    Then in test setup file, we have used this util function here -

  const colorsPath = path.resolve("src/styles/_colors.scss");  //filepath to pass in utils function
  const cssVars = extractCssVars(colorsPath);   //here is utils function, giving colors in objects array

  function applyCssVars(vars: Record<string, string>) {
    const style = document.documentElement.style;
    for (const [key, value] of Object.entries(vars)) {
      style.setProperty(key, value);
    }
  }
  applyCssVars(cssVars); // looping through array and returning value like this for each color - document.documentElement.style.setProperty('--primary', '#fff')

**IMP** - if we will not inject these colors in document, then all tests will fail because we are giving theme provider in setup.
