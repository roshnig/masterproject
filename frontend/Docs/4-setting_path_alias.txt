# Path Alias
Path aliases let you replace long or deeply nested relative imports like this:
import Button from '../../../../components/ui/Button'
in much cleaner way -
import Button from '@components/ui/Button'

## Option 1- set alias manually ##

step 1- in vite.config.json
  export default defineConfig({
  resolve: {
    alias: {
      '@components': path.resolve(__dirname, './src/components/file.tsx'),  //so instead of './src/components/file.tsx, you can use @component
      '@utils': path.resolve(__dirname, './src/utils'),
      '@assets': path.resolve(__dirname, './src/assets'),
      //add more paths if you want to add more path alias
    },
  },
  )}

Step 2- Add same in vitest config if you have seperate vitest.config file

Step 3- Add in paths in tsconfig.json
{
  "compilerOptions": {
    "baseUrl": "./",
    "paths": {
      "@components/*": ["src/components/*"], //so instead of './src/components, you can use @component
      "@utils/*": ["src/utils/*"],           //instead of './src/utils, you can use @utils
      "@assets/*": ["src/assets/*"]          //instead of './src/assetss, you can use @assets
      //add more paths if you want to add more path alias
    }
  }
}
