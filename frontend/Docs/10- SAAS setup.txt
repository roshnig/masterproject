Step 1- npm i sass-embedded

Step 2- Add src/styles folder - in here

Step 3 - add index.scss file and 
a reset.scss file (resets default styles. add this in main tsx)

Step 4- add _variables.scss, _mixins, colours.scss files

Step 5 - in vite.config.ts file , add this -
css: {
    preprocessorOptions: {
      scss: {
        // This injects variables and mixins into every .scss file
        additionalData: `
          @use "/src/styles/variables.scss" as *;
           @use "/src/styles/colors.scss" as *;
            @use "/src/styles/mixins.scss" as *;
             @use "/src/styles/index.scss" as *;
        `,
      },
    },
  },

Step 6-  Add component.module.scss file. and add your styles here.
  After above setup, we need not to import variables, mixins, colors in each and every scss file like below
  @use "../../../styles/variables.scss" as vars // not required due to vite setup
  we can use them directly use it like below in your scss file-
  color: $color-bg-default  // if vite setup not done, then use  vars.$bg-color

Step 7- use scss file styles in component -

  import styles from scss file like below -
  import styles from "./component.module.scss";
  then add class names like this-
   className={styles.icNavItem}

Step 8-   How to use queries 
{
   background-color: $color-bg-default;
   @include tablet {
    background-color: green;   // this means on tablet screen size, bg color will change to green
   }
   @include desktop {
    background-color: red;   // can use any variable colors here
   }
}

**************** Examples - how to use inside your component.scss file ******************
.container {
  @include flex-center; // ✅ Works automatically
  background-color: $color-primary; // ✅ Works automatically
}
.button {
  @include flex-center;     //from mixin
  background-color: $color-primary;
  color: white;
  padding: 0.6rem 1.2rem;
  border: none;
  border-radius: 6px;
  font-size: 1rem;
  cursor: pointer;
  @include transition(background-color, 0.5s, ease); //time and ease has default values in mixin so can skip

  &:hover {
    background-color: darken($color-primary, 8%);
  }
}
