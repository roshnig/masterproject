Option 2- vite doesn't automatically optimize images for build but we can install a plugin

npm install vite-imagetools --save-dev

then in in vite config - 
import {imagetools} from 'vite-imagetools';
 then add this pugin with react() plugin - imagetools()
 plugins: [react(), imagetools()]

now import your images like below - wherever you want them-
import optimizedLogo from './logo.jpg?w=200;400;800&format=webp;avif&as=picture';

 this will generate optimized version automatically.
 ?w=200;400;800 means generate multiplw images with width 200px, 400px, and 800px
 &format=webp;avif means generate image in multiple formats - webp and avif. these are modern compressed formats.
 &as=picture means output a <picture> element. This lets the browser chosse the best version (format + size) automatically.

 use it -
 import optimizedLogo from './logo.jpg?w=200;400;800&format=webp;avif&as=picture'; // if you want responsive format and size
 or
 import small from './logo.jpg?w=200;'

 <picture>
  {optimizedLogo.sources.map((source)=> (
    <source key={source.type} srcSet={source.srcSet} type={source.type} />
  ))}
  <img src={optimizedLogo.img.src} alt='logo' width={optimizedLogo.img.width} />
 </picture>

 browser will automatically pick the smallest width that fits its screen and pick most efficient format it support.
