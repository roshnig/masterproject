************** Optional - Add src/tests/ test-utils file **************
when we have router, theme providers etc. we will require a utils file for tests.
otherwise tests will fail. here we will setup 
- MemoryRouter (instead of Browser Router used in main.tsx, need to use it in tests). it matches BrowserRouter in main.tsx
- wraps components in theme context (Appthemeprovider) so light/dark mode works in tests.
- mockNavigate allows you to verify calls to useNavigate
- supports setting an initial route via route option
